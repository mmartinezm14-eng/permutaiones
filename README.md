# Permutaciones

Software del trabajo colaborativo contextualizado (unidades 1 y 2).

**Tema:** Permutaciones (lineal, circular y con repetición).

## Funcionalidades
- Permutación de n elementos: n!
- Permutación lineal sin repetición: P(n, r)
- Permutación circular: (n-1)!
- Permutación con repetición: n! / (n1! · n2! · ...)

## Cómo usarlo
1. Descarga o clona el repositorio.
2. Abre `index.html` en el navegador (no requiere instalación).
3. Elige la operación, escribe los datos y pulsa **Calcular**.

## Casos de prueba
En la sección "Casos de prueba" se escribe la operación, los datos y el resultado esperado. Al pulsar **Ejecutar pruebas**, el programa calcula el resultado y lo compara con el esperado. Para un caso inválido se escribe `ERROR` como esperado.

## Archivos
- `index.html`: estructura de la página
- `styles.css`: estilos
- `script.js`: lógica de las permutaciones, interfaz y pruebas
